# Student Performance Analysis

## Project Overview

This project analyzes student performance based on performance,
attendance, age-group, gender and exam scores.

## Tools Used

- Excel
- SQL
- NumPy
- Matplotlib
- Power BI

## Dataset

The dataset contains student information such as:

- Student Name
- Age
- Gender
- Attendance
- Percentage
- Performance
- Average
- Subject - wise scores
- Exam Score

## Analysis

### Excel
- Data cleaning
- Missing value handling
- Basic calculations

### SQL
- Average exam score
- Performance by gender
- Top-performing students
- Attendance-based analysis

### NumPy
- Mean
- Median
- Standard deviation
- Correlation analysis

### Power BI
Created an interactive dashboard showing:

- Average Exam Score
- Average Attendance
- Average Study Hours
- Study Hours vs Exam Score
- Attendance vs Exam Score
- Top 10 Students
